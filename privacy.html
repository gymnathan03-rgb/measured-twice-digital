Habibi Privacy Policy

Last updated: October 28, 2026

Habibi is a personal voice assistant built and operated by Measured Twice Digital for its own use. It runs on the owner's own computer and phone. This policy explains what Google account data Habibi uses and what happens to it.

Data Habibi accesses

  • Google Calendar events (scope calendar.events): the titles and times of upcoming events, so Habibi can tell the owner what is coming up, and the ability to add events when the owner asks.
  • YouTube account data, read-only (scope youtube.readonly): the names and contents of the owner's playlists, so Habibi can play them on request.

Habibi does not access email, files, contacts, or any other Google data, and it cannot post, edit, or delete anything on YouTube.

How the data is used

The data is used only to provide the features described above to the account owner. It is not used for advertising, not sold, not shared with other people, and not used to build or train AI models.

Where the data is stored

Habibi keeps its Google sign-in token on the owner's computer, encrypted so that only that Windows user account can read it. Calendar and playlist information is fetched when needed and is not copied to any server run by Measured Twice Digital. There is no Habibi server.

Third-party processing

When the owner asks Habibi a question, the text of the request, which can include event titles or playlist names relevant to that request, is sent to Anthropic's Claude service so a reply can be produced. That text is sent only to answer the request. Anthropic's handling of it is governed by Anthropic's own terms and privacy policy.

Google API Services User Data Policy

Habibi's use and transfer to any other app of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Your control

The owner can revoke Habibi's access to Google at any time at myaccount.google.com/permissions, and can delete the saved sign-in by deleting Habibi's token files on the computer.

Changes

If this policy changes, the new version will be posted on this page with a new date.

Contact
